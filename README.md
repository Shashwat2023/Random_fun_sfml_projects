# Random Fun SFML Projects

Small SFML projects I made for fun while learning SFML and C++.

Nothing too serious — just experiments, mini-projects, and random ideas I built while learning.

## Projects

### `window_reposition.cpp`
A small experiment where the SFML window can be moved around the screen using **W/A/S/D** and smoothly returns to the center when no movement key is pressed.

Concepts explored:
- SFML window positioning
- Keyboard input
- `sf::Clock` and delta time
- Frame-independent movement
- Basic boolean state handling

More small SFML experiments will be added as I learn.
